# Solotik app (Android and Windows)

The Solotik hotspot voucher system as an app. It opens your website (unifiedtik.com) and adds what a website cannot do:

* **Find routers on the network this phone or computer is on** (MikroTik announcements and the RouterOS API port),
  with their name, model, IP and MAC address. Only the router password is typed.
* **Reach the router for the website** while the app is open on the router's network: connect, set up the hotspot,
  monitor, users, backups. Nothing is opened on the router or on Starlink; the app only makes outgoing HTTPS calls.
* **Save tickets** (PDF, CSV): on Android through the share sheet (Files, Drive, print, WhatsApp), on Windows with a
  Save dialog.

## Download

Every change to `main` builds the apps on GitHub and publishes them under **Releases**:

* Android: `Solotik.apk`
* Windows: `Solotik-Setup.exe` (installer), or `Solotik-Windows.zip`

Stable links to the newest version:
`https://github.com/thorgrante/solotec/releases/latest/download/Solotik.apk` and
`https://github.com/thorgrante/solotec/releases/latest/download/Solotik-Setup.exe`.

## Code

| File | What it does |
|---|---|
| `lib/main.dart` | Start-up: install ID, device name, the connector, the app |
| `lib/web_shell.dart` | The website full screen; other sites open in the browser; "Can't reach the server" screen |
| `lib/bridge.dart` | `window.HVNative` in the page: link this install to a branch, save files |
| `lib/connector.dart` | The line to the website (`/api/portal/connector/poll`) and its jobs: scan, probe, open, run, close |
| `lib/discovery.dart` | Finding devices: MNDP (UDP 5678), API/web port sweep of this device's /24 networks, web page, ARP (Windows) |
| `lib/routeros.dart` | RouterOS API client (8728, 8729), including the pre-6.43 login |
| `lib/lan.dart` | Connections to devices on the shop network, made on the Wi-Fi itself on Android (a hotspot Wi-Fi with no internet before login is otherwise skipped for mobile data) |
| `android/app/src/main/...` | Permissions; MainActivity: device name and the Wi-Fi multicast lock for router announcements |
| `windows-installer/solotik.iss` | Inno Setup script for the Windows installer |
| `.github/workflows/build.yml` | Builds the APK and the Windows app and publishes a release |

The Android and Windows project folders are generated by `flutter create` during the build; only the files above
are kept here.

Server side (in the website package): `site.js` (`POST /api/connector/self`, the connector line) and the
Auto Find Device code in the app page.
